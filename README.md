# Semester 2 Mark Calculator (2026)

A mark calculator for seven Stellenbosch University AgriSciences modules, using the weightings and rules in each 2026 module framework:

- AGR 343 – Agronomy 343
- GEN 244 – Genetics 244
- HORT 352 – Horticulture 352
- NEM 344 – Nematology 344
- SS 344 – Soil Science 344
- PP 344 – Plant Pathology 344
- AGR 341 – Agronomy 341

## How to use

1. Open the page and pick a module tab.
2. Type each mark as a percentage (`68`) or a score (`34/50`). Leave anything you haven't written yet blank.
3. Your final mark so far updates with every mark. When all other marks are in, the bottom of the page shows the mark you need in the last test for 50%, 60% or 75%.

Marks are saved only in your own browser. Nobody else can see them.

## Disclaimer

This is an unofficial study aid. Announcements on STEMLearn and your lecturers' rulings override anything in this calculator.
Note: the PP 344 theory exam entry is set to a 40% theory semester mark in this calculator; the 2026 framework states 50%.
